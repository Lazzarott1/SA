# SA

Proposta do Sistema:

Nosso sistema tem como objetivo apresentar de forma visível e clara informações pertinentes para o controle ferroviário, como por exemplo: velocidade, temperatura, status, localização, entre outros. Organizando todas essas informações em um Dashboard, permitindo assim uma visialuzação clara e direta de todos os dados importantes, controle otimizado de todos os dados, com a possibilidade de uma regeração  de relatórios personalizados
